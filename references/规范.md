# 文档格式规范

> 本规范规定项目交付文档的页面、字体、段落、标题、图表、公式等统一格式要求，适用于各类设计文档、技术报告、用户手册、运维手册等正式交付文档的编写、排版与验收。
>
> 单位换算：长度单位为磅（pt），必要时标注 twip，1 磅 = 20 twip。

---

## 一、总则

1. 全文格式必须统一：同一层级、同一要素的字体、字号、间距、编号方式在全文中保持一致。
2. 本规范未单独规定的要素，按同类正式文档通例处理，并与全文风格保持协调。
3. 文档须自封面至末章顺序完整：**封面 → 修订记录 → 目录 → 正文各章**。
4. 最终交付前须导出 PDF 复核排版效果，确保无内容溢出、无错版、无失效引用。

---

## 二、页面设置

| 项目 | 取值 |
| --- | --- |
| 纸张 | A4（210 × 297 mm） |
| 上、下页边距 | 2.54 cm |
| 左、右页边距 | 3.17 cm |
| 页眉距上边界 | 1.5 cm |
| 页脚距下边界 | 1.75 cm |
| 装订线 | 无 |
| 文档网格 | 按行排版，行网格间距 15.6 磅 |
| 分节 | 封面、目录、正文各自独立分节 |

> 版心宽度 = 210 − 3.17 × 2 ≈ **15.66 cm**（对应 8306 twip），全文所有表格总宽与该值对齐。

## 四、段落与间距

### 1. 章标题

| 属性 | 取值 |
| --- | --- |
| 对齐 | 两端对齐 |
| 段前 / 段后 | 17 磅 / 16.5 磅 |
| 行距 | 2.4 倍行距 |
| 缩进 | 无（顶格） |

### 2. 一级节标题

| 属性 | 取值 |
| --- | --- |
| 对齐 | 两端对齐 |
| 段前 / 段后 | 13 磅 / 13 磅 |
| 行距 | 约 1.72 倍行距 |
| 缩进 | 无（顶格） |
| 其他 | 与后继正文保持同页（避免标题落在页脚处孤立） |

### 3. 正文段落

| 属性 | 取值 |
| --- | --- |
| 对齐 | 两端对齐 |
| 行距 | 固定值 20 磅 |
| 首行缩进 | 2 个汉字 |
| 段前 / 段后 | 0 |

### 4. 通用规则

- 各级标题**顶格**，不缩进；正文首行缩进 2 个汉字。
- 表格内段落、题注段落、公式段落**不适用**首行缩进。
- 两个标题相连、中间无正文时，后一个标题段前距设为 0 磅。
- 段落间距必须与行距属性**配套设置**，避免因属性缺失导致排版引擎在保存时清除段前段后间距。

## 五、标题与编号

1. 标题分四级：章标题、一级节标题、二级节标题、三级节标题。
2. **章标题**采用自动编号，形式为**阿拉伯数字加顿号**：`1、`、`2、`、`3、`……编号后不加分隔符。
3. **节标题**采用与章号联动的多级编号，编号写入标题文本：
   - 一级节标题：`1.1`、`1.2`……
   - 二级节标题：`1.1.1`、`1.1.2`……
   - 三级节标题：`1.1.1.1`……
4. 标题文字与编号之间不加空格；正文引用时按编号书写（如「见 2.3 节」）。
5. 标题层级不得超过四级；确有更深层次，改用正文加编号段落表达。

## 六、封面、修订记录与目录

### 1. 封面

封面独立成页，自上而下依次为：

| 顺序 | 内容 | 字号 |
| --- | --- | --- |
| 1 | 适当留白（抬高主标题） | — |
| 2 | **项目 / 系统名称** | 18 磅加粗 |
| 3 | **文档类型**（如「运维手册」） | 18 磅加粗 |
| 4 | 适当留白 | — |
| 5 | 模块 / 项目名称 | 14 磅加粗 |
| 6 | 年月（如「2026年9月」） | 14 磅 |

### 2. 修订记录

紧跟封面，采用表格形式，列依次为 **日期 / 版本 / 说明 / 作者**；表头用小五号，表体用五号；每次内容修改须新增一行，保持历史可追溯。表格宽度与版心对齐。

### 3. 目录

- 位于修订记录之后，独立成页，页首居中标题「**目录**」（五号）。
- 目录由**域自动生成**，收录一级、二级标题，页码为**真实页码**，禁止手工填写。
- 一级条目顶格，二级条目缩进 2 个字符，条目与页码之间用点线引导、页码右对齐。
- 生成后须刷新域，确认条目完整、页码正确、无「未定义书签」错误。

---

## 七、页眉与页脚

### 1. 页眉

- 文案：`<项目 / 系统名称> - <文档类型>`（如 `XXX系统 - 运维手册`）。
- 格式：宋体小五（9 磅）、**斜体**、居中。
- 名称与文档类型之间用半角空格 + 连字符 + 半角空格（` - `）连接。

### 2. 页脚

- 文案：`第 X 页`，页码为域自动生成，居中。
- 格式：宋体小五（9 磅）。
- 封面不显示页码；自目录或正文起显示页码，正文页码从 1 起重新编号。

## 八、表格

| 项目 | 取值 |
| --- | --- |
| 边框 | 单线条，线宽 0.5 磅；上、下、左、右及内部横竖线齐全 |
| 总宽 | 与版心宽度一致，各列列宽之和等于表宽 |
| 布局 | 固定列宽 |
| 对齐 | 表格整体居中 |
| 表内文字 | 五号（10.5 磅），中文宋体、西文 Times New Roman |
| 跨页 | 表格行不跨页；尽量使整表不跨页 |
| 引用 | 表前正文必须有文字提示（如「见表 2-1」） |

## 九、图与题注

| 类型 | 位置 | 对齐 | 段前 | 段后 | 字号 |
| --- | --- | --- | --- | --- | --- |
| 表题 | 表格**上方** | 居中 | 12 磅 | 6 磅 | 宋体五号（10.5 磅） |
| 图题 | 图片**下方** | 居中 | 6 磅 | 12 磅 | 宋体五号（10.5 磅） |

1. 编号采用**分章连续编号**，形式为 `图X-Y` / `表X-Y`（X 为章号，Y 为章内序号，从 1 起）。
2. 表题须与表格保持同页；图与图题为一体，**严禁拆开跨页**。
3. 题注段落不适用首行缩进。

## 十、公式

公式分**行间公式**与**行内公式**两类，二者在位置、编号与使用场景上要求不同，但**均须以可编译的公式对象录入**。

### 1. 行间公式（独立成行的公式）

- **位置**：单独占行，公式本体**居中**书写。
- **编号**：采用分章连续编号，序号置于该行**右端对齐**，形式为 `(X-Y)`（如 `(2-1)`）；编号不得省略。
- **间距**：公式段落**段前、段后各 6 磅**；行距与正文协调。
- **折行**：公式过长需折行时，在关系符（`=`、`≈`、`≤`、`≥` 等）处换行，并使关系符纵向对齐。
- **引用**：正文引用行间公式时写作「如式 (2-1) 所示」。

### 2. 行内公式（嵌于正文中的公式）

- **位置**：随文字排版，**不单独占行、不编号**。
- **字号**：与所在段落正文一致（小四 12 磅）；变量按数学惯例用**斜体**。
- **间距**：公式前后不额外添加空格，由排版引擎按数学间距自动处理。
- **适用场景**：简短符号、单变量、简短表达式（如 `x`、`α`、`f(t)` 等）。**结构复杂或需要编号的公式，一律改为行间公式。**

### 3. 共同要求（可编译）

1. **行间公式与行内公式都必须以可编译的公式对象录入**（OOXML 数学标记 / Word 公式对象），确保公式**可编辑、可重新渲染**。
2. **禁止**使用图片、截图、纯文本字符拼凑，或用「普通符号 + 上标/下标格式」代替公式。
3. 变量用**斜体**、常量与计量单位用**正体**；函数名（`sin`、`log`、`max`、`exp` 等）用正体。
4. 同一文档中，行间公式与行内公式的字体与变量体例必须**保持一致**。
5. 公式与公式编号视为一个整体，不得与上下文拆页。

## 十一、脚注与文献引用

### 1. 脚注

- 字体：小五号（数字用 Times New Roman 9 磅）；**单倍行距**；悬挂缩进 1.5 字符；段前段后 0 磅。
- 序号采用「**①**」样式，**按页单独编号**。

### 2. 文献引用

- 采用**顺序编码制**，置于引用末尾右上角**上标**，如 `[1]`、`[1,5,14-17]`。
- 文献作者写到**第三位**，余者用「，等」或「et al」。
- **不得在各级标题处标注引用。**

## 十二、编写与交付要求

**格式一致性**
- [ ] 同级标题、同类要素的字体、字号、间距、编号方式全文统一
- [ ] 各级标题顶格，正文首行缩进 2 汉字

**结构完整性**
- [ ] 封面、修订记录、目录、正文齐全
- [ ] 目录由域生成，条目完整、页码正确、无「未定义书签」

**图表**
- [ ] 表格线宽 0.5 磅单线，总宽与版心一致，行不跨页
- [ ] 表题在表上、图题在图下，均居中且编号连续
- [ ] 表格 / 图片与对应题注不拆页

**公式**
- [ ] 行间公式居中、右端编号、段前段后各 6 磅
- [ ] 行内公式随文排版、不占行不编号、字号与正文一致
- [ ] **两类公式均为可编译的公式对象，无图片或字符拼凑**

**最终复核**
- [ ] 已导出 PDF 复核，无内容溢出、无错版、无失效引用
- [ ] 文档标题属性与文件名一致
